# NabyScape 3.0.0 — Rust rewrite with voice built in

This release replaces the WPF/.NET app with a native Rust build. Speech works on your PC out of the box, and short instructions no longer need a chat model.

## Voice on this PC

- **Whistle** listens and **Piper** speaks. Both ship inside the installer, so nothing downloads. Choose Spanish voices by gender, or add your own Piper voice (`.onnx`).
- The wake word listens for "Hey Naby" or "Oye Naby". The microphone stays open while it is on; the Wake word page says which engine listens.
- Whistle can run with `needle.exe` (recommended) or with Python (`pip`), kept in its own virtual environment. Only the `pip` option shows your words live while you speak.
- Naby no longer answers itself: the microphone waits briefly after a reply and ignores words it just said. A sentence a small local model repeats is read once. This addresses reports of the same text being read several times; it has not been confirmed on real speakers yet.

## Quick commands

Off by default: **Settings → Voice → Models → Quick commands**.

Short instructions run on this PC with no reply, in chat and in voice: pause, play or skip music, set the volume, mute, start a timer, open a page. Anything else goes to your chat model as before.

They use Cactus Needle 3, fine-tuned for Spanish and these commands (`needle3-es.cact`, 63 MB, shipped in the installer). On a 64-phrase test the model had never seen:

| | Base model | Tuned model |
| --- | --- | --- |
| Commands right | 24 of 34 | 29 of 34 |
| Wrong action | 5 | 1 |
| Actions on plain conversation | 16 of 30 | 4 of 30 |

The app also requires the words of your request to back every action, so "no pauses la música" or "el siguiente capítulo es largo" do nothing and go to chat. It uses about 134 MB for about a second, only when a phrase looks like a command. The test phrases were typed, not spoken.

## Island

- A maximized or fullscreen app tucks the island instead of hiding it. Clicking beside the island tucks it; a click elsewhere brings it back.
- Lower CPU while the pointer moves over the panel, less memory with Settings open, better text contrast and fixed sidebar tooltips.

## Install

Download `NabyScape-win-x64-Setup.exe` (126 MB). It contains everything; the installer is unsigned, so Windows may warn you. Check it against `SHA256SUMS`.

## Limits of this release

- **x64 only.** There is no ARM64 package in 3.0.0, because the machine that built it lacks the ARM64 build tools.
- Installation through the Setup and the tuned model inside the running app were not exercised end to end. The package contents, its self-test and the router from the portable files were.
